# Tcl/Tk runtime notices

These unmodified license texts correspond to the Tcl/Tk 8.6.13 runtime bundled
with the supported CPython 3.12.7 Windows installer. Its installer need not
include standalone `tcl/tcl8.6/license.terms` or `tcl/tk8.6/license.terms`.
The collector prefers installed notices and otherwise uses these checked copies.

Sources (official CPython dependency tags):
- https://raw.githubusercontent.com/python/cpython-source-deps/tcl-core-8.6.13.0/license.terms
- https://raw.githubusercontent.com/python/cpython-source-deps/tk-8.6.13.0/license.terms

Version reference:
https://github.com/python/cpython/blob/v3.12.7/PCbuild/tcltk.props

SHA256 checksums are enforced in scripts/collect_licenses.py. No network is
required during license collection. Missing or modified fallback notices fail.
